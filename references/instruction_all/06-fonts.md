# Шрифты в теме WordPress

- Основной формат локальных веб-шрифтов — WOFF2. Подключаем реально используемые начертания и нужные языковые подмножества, а не произвольное полное семейство.
- Для нового сайта шрифт определяется заданием или дизайном; если не указан, подбираем по задаче. Google Fonts допустим как источник, но не является обязательным ограничением.
- При переносе определяем фактические семейства, веса, наклон, метрики и подмножества оригинала. Не заменяем фирменный шрифт похожим без согласования; недоступность нужного файла обозначаем.
- Файлы храним в `assets/font/` с понятными именами. Разным подмножествам и начертаниям не назначаем одно имя файла.

```css
@font-face {
  font-family: 'ProjectFont';
  src: url('../font/ProjectFont-Regular.woff2') format('woff2');
  font-weight: 400;
  font-style: normal;
  font-display: swap;
}
```

Это пример пути из `assets/css/main.css`, а не выбор шрифта для всех проектов. Для variable font указываем фактический диапазон весов; `unicode-range` сохраняем, если он нужен для разделённых подмножеств.

- Предзагрузку добавляем только для критических файлов первого экрана через WordPress, с корректным URI, типом и CORS-атрибутами. Не предзагружаем всё семейство.
- Проверяем загрузку без 404 и подстановки резервного шрифта, кириллицу, жирное начертание и переносы строк после загрузки.
- При локализации внешнего CSS обновляем относительные URL шрифтов. Не допускаем зависимости рабочего сайта от домена разработки.
