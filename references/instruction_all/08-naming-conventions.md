# Именование в теме WordPress

| Объект | Соглашение | Примеры |
| --- | --- | --- |
| Шаблоны WordPress | Имена иерархии и kebab-case для дополнительных шаблонов | `front-page.php`, `page.php`, `single-service.php` |
| Части шаблонов | kebab-case внутри `Parts` | `Parts/common/contact-card.php` |
| CSS и JS | kebab-case | `main.css`, `media.css`, `main.js` |
| Файлы изображений | kebab-case, без пробелов и кириллицы | `hero-bg.webp`, `logo-white.svg` |
| Шрифты | Понятные семейство, начертание и подмножество | `ProjectFont-Regular-cyrillic.woff2` |
| Папки ресурсов | kebab-case | `assets/lib/swiper-slider` |
| PHP-функции и handles | Префикс проекта и единое соглашение | `project_contacts`, `project-main` |
| JS-переменные и функции | camelCase | `headerMenu`, `initAccordion` |
| CSS-переменные | kebab-case по смысловым группам | `--color-primary`, `--container-width` |

`Parts` — принятое имя папки с заглавной буквы. Регистр во всех подключениях должен совпадать; в существующем проекте сохраняем уже выбранное имя папки.

## Классы

- Блок: `.catalog`, элемент: `.catalog__item`, модификатор: отдельный `._is-active`.
- В HTML: `class="catalog__item _is-active"`; в CSS: `.catalog__item._is-active`.
- Не используем `--modifier` и модификатор, слитный с именем блока. Не строим цепочки `.block__element__child`; дочерний самостоятельный компонент получает собственный блок.
- Классы WordPress, Contact Form 7 и библиотек не переименовываем: добавляем свои классы и сохраняем интеграцию.

## Поля и данные

- Метки полей, пунктов меню и типов записей понятны заказчику и отображаются по-русски. Внутренние имена и ключи стабильны, обычно в snake_case и с нужным префиксом.
- Не переименовываем сохранённые ключи ACF, типы записей и таксономии без переноса связанных данных. Иначе заполненные значения и адреса могут перестать находиться.
- При нормализации скачанных ресурсов сохраняем соответствие старых и новых путей, включая ссылки внутри CSS и JS.
- Адреса страниц WordPress задаются структурой сайта; имена PHP-файлов не становятся автоматически URL страниц.
